## 📌 Overview

This repository contains a collection of **SQL tasks and practical exercises** completed as part of the **Digilians – IntAIVE Initiative**, conducted **under the supervision of the Ministry of Communication and Information Technology (MCIT)**.

The tasks focus on using **Structured Query Language (SQL)** to efficiently store, retrieve, manipulate, and analyze data, following **best practices used in real-world database environments**.

---

## 🎯 Objectives

The objectives of this repository are to:

* Strengthen proficiency in **SQL fundamentals and advanced queries**
* Design and query **relational databases**
* Perform **data retrieval, filtering, aggregation, and analysis**
* Apply SQL to solve **real-world data problems**
* Write clean, optimized, and readable SQL queries
* Develop a solid foundation for **data analysis and data science roles**

---

## 🧠 Topics Covered

This repository includes tasks covering:

* Database Concepts and Relational Models
* SQL Data Types and Constraints
* `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`
* Aggregate Functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
* `GROUP BY` and `HAVING`
* Joins (`INNER`, `LEFT`, `RIGHT`, `FULL`)
* Subqueries and Nested Queries
* Views and Indexes
* Data Manipulation (`INSERT`, `UPDATE`, `DELETE`)
* Basic Query Optimization
